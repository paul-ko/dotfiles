# Keystrokes worth remembering

Curated, not exhaustive — `:help index` has the full list of Neovim's built-in keys per mode.
This is just the ones easy to forget that turned out to be useful. Add to it as more come up.

## Normal mode
- `CTRL-O` — jump to the older position in the jumplist (`:help CTRL-O`)
- `CTRL-T` — pop the tag stack, i.e. jump back after a tag/definition jump like `<C-]>` or `gd`
  (`:help CTRL-T`)
